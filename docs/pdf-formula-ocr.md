# PDF 公式转写

解析版本 `pdf-page-v3-latex` 按页处理新 PDF。可复制的文字层仍作为正文保存；含数学线索的页面会额外调用现有受预算约束的 PDF 视觉模型，只转写原页可见公式，附加为可复制的 `\[...\]` LaTeX。扫描页若本地 OCR 已得到文字，也走同一数学线索判断。没有本地文字的页面由现有整页视觉转写处理，并要求公式采用 LaTeX。

模型失败、预算不足或公式无法辨认时，已有文字仍被保存，页面会提示核对原 PDF。模型公式是视觉转写结果，不保证每个符号都正确；文字层没有明确数学线索的公式可能漏检。页码与原文保留，搜索索引同时包含原文及识别出的 LaTeX。旧版页面在重新解析期间继续显示，解析成功后才替换索引。

**费用与隐私：**每个触发视觉识别的页面可能产生一次额外 OpenAI Responses 请求；请求包含该页 PDF 和最多 12,000 字符的本地文字，`store:false`。新增的公式视觉请求最多每份 PDF 24 页、每天（UTC）60 页，并受现有 AI 月预算约束。达到上限时保留本地文字并提示核对原页。未触发数学线索的文字层页面不会新增模型调用。现有无本地文字页的整页转写仍沿用原预算流程，不计入本新增公式请求上限。

**旧资料：**默认部署后不会把已完成的历史 `pdf-page-v2` 文档入队重解析；旧文字与搜索继续可用。用户可在该 PDF 的文字版本点击“重新识别这份 PDF 的公式”，只将这份文档加入现有索引队列。任务期间预览保留旧版文字，成功后自动刷新；失败时显示可重试状态。重复点击沿用同一文档任务，不能并发计费。原本处于 pending/error 的文档仍按原有后台重试路径恢复。只有运行环境显式设置 `PDF_FORMULA_BACKFILL=true` 并重启工作进程，已完成的历史 PDF 才会批量逐步重新解析。停止批量回填时撤销该变量并重启工作进程；已在执行的一页需等请求结束。原 `pdf-page-v2` 页面仍保留；搜索索引保留最近一次成功版本。若需要完全回退已经重建的索引，应从备份恢复或执行专门的旧版重建流程。上线前先核对待处理文档数量与预算，再启用批量回填。

**上线验收：**选一份可公开使用、含上下标、分式和积分的学术 PDF，以及一份公开扫描页。逐页核对输出的 LaTeX 与原页符号、页码、正文搜索；另用纯文字 PDF 验证无额外公式请求。检查预算账本和失败页提示。不要把私人课程资料放进测试仓库或公开服务。

开发验收使用一页临时生成、视觉检查过的合成 PDF，包含 `E = mc²`、`(a+b)/c = 2` 与 `∫₀¹ x² dx = 1/3`。一次真实 `gpt-5-mini` PDF 视觉请求返回 `E = mc^{2}`、`\frac{a + b}{c} = 2`、`\int_{0}^{1} x^{2}\, dx = \frac{1}{3}`，与该样例匹配。调用使用同一受预算的 Responses 包装，HTTP 200；临时 PDF 与响应脚本未纳入版本库。这只能证明此简单样例，不能外推到复杂或低质量扫描件。单元测试另用模拟结构化响应验证页码、正文保留、错误回退和每日限额，并不测视觉识别准确率。
