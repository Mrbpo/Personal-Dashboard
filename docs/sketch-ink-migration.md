# 绘画问 AI 的逐笔画页

Issue #26 将画页从只有 `image_hash` 的 PNG 扩展为 PNG 加逐笔数据。`strokes_json = NULL` 表示旧版位图页；`[]` 表示已迁移、目前没有新笔画。客户端只在抬笔后提交一次笔画改动，自动保存仍合并连续书写，并在每次保存时从同一笔画快照重新生成合成 PNG。AI 和手动 PDF 继续读取合成 `image_hash`，历史 PDF 与文字记录不改写。

首次编辑旧页时，服务端在同一事务里把原 `image_hash` 放入 `base_image_hash`，新笔画写入 `strokes_json`。画布先绘制旧底图，再绘制新笔画。旧 PNG 没有可识别的单笔，整笔橡皮只命中新笔画；界面会明确提示。已有位图不会被擦笔、撤销或“清除新笔画”静默删除。用户明确确认“清空整页”时，服务端保留清空前的合成图、底图和逐笔 JSON；在空白页上可直接恢复，刷新后也可恢复。

每页保存使用页 revision 比较。旧浏览器标签仍可保存尚未迁移的 PNG 页；一旦页有逐笔数据，缺少 `strokes` 的旧客户端写入会被拒绝，避免 PNG 与 JSON 分叉。客户端的本地备份包含 PNG、逐笔快照和 revision；断线后同版本可重试，版本变化时保留备份供下载核对，不自动覆盖。旧版只有 PNG 的本地备份继续以旧格式恢复，避免升级时丢画。
