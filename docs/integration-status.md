## 操作说明

保持网站使用现有启动方式。独立任务进程使用 `npm run worker`，与网站分开运行。只有选定主节点才设置 `SYNC_PRIMARY=true`；其他节点不得自动同步。

已有 Canvas 下载目录可显式导入：`npm run import:library -- --dir <某一课程目录> --course <Canvas课程ID> --url <网站地址>`。不会递归扫描整个电脑，也不会上传浏览器目录。

服务器操作、备份保留和恢复限制见 `deploy/README.md`。上线前需要用户确认 GitHub 账户归属、服务器/域名和 Gmail 授权；目前未执行任何远程发布。
