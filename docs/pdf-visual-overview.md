# 全页总览与细节视图（Issue 168）

显式选页、图像输入且启用四图模式时，可传入 `overviewImage: true`。同一原始页的完整可见 CropBox 作为第一张 PNG，随后按既有顺序发送四张细节图；仍是一次 mini 请求。总览保留原旋转和内容流，用于整页阅读顺序及跨视图衔接，不能用来推导原件没有的内容。

默认关闭。既有四图、单图、PDF输入模式保持原行为和缓存身份；新配置使用独立 identity，不覆盖历史转写。所有图片成功渲染后才调用 provider；原完整性、数学结构和不确定片段检查保持。

一个新增正式入口检查核对完整总览/原内容流/旋转、五图标签顺序、新旧缓存隔离与复用，以及总览失败不发请求；类型检查通过。既有几何测试不重复跑。全页内容保真仍须通过原图对照，不能由完整标记或代码检查推断。

仅规划对已有失败样例09、22各做一次真实隔离对照；不是新的盲测通过批次，不改生产。
