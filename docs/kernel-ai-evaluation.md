# Kernel AI 问答：隔离验收

## 范围与来源

`/kernel/ask` 从 PostgreSQL `KernelService` 读取课程、任务和日程的确定性状态；从现有归档读取长篇学习材料，并在回答中显示实际使用的来源。基准测试只使用隔离数据库，不写入 v0 或生产服务。

| 数据集 | 真实来源 | 在测试中的用途 |
| --- | --- | --- |
| [SyllabusQA](https://github.com/umass-ml4ed/SyllabusQA) | 63 份匿名化真实课程大纲及官方问答 | 多课程大纲、日期、规则、评分与先修要求；50 题 |
| [QASPER](https://huggingface.co/datasets/allenai/qasper) | 研究论文全文、问题及人工标记段落 | 多篇长文里的证据定位与答案；50 题 |
| [CourseAssist-Data](https://github.com/ytyfeng/CourseAssist-Data) | 匿名化真实 Piazza 问答与部分作业上下文 | 论坛检索和回答 50 题，另测 20 题中文改写 |
| [HotpotQA](https://hotpotqa.github.io/) | 多文档问答与 9,769 个背景条目 | 跨文档链接的额外压力测试；不把百科内容称作课程资料 |
| 混合课程集 | 受控模拟 Canvas 作业、PDF 课件、邮件、Piazza 教师答复与学生猜测；混入公开大纲及背景资料 | 10 门课、50 个跨来源问题；验证优先级、课程隔离与证据拼接。模拟来源只用于集成验证，不冒充真实 Canvas/Piazza 数据。 |

CourseAssist 的 `Context` 字段是数据集发布的课程上下文，**不是 Canvas 导出**。真实论坛问题与混合模拟集分开统计。

## 结果与验收口径

下列数值来自本地代码和隔离 PostgreSQL。`50/50` 仅说明对应的测试断言通过，不代表所有真实课程问题正确。

| 检查 | 结果 | 解释 |
| --- | --- | --- |
| PostgreSQL Truth Layer | 50/50 | 5 门课程、25 个截止日期、10 个状态、10 个事件；含仅日期与精确时间 |
| 混合课程检索 | 50/50 | 每题所需的 Canvas/PDF/Piazza 证据都进入候选；资料库有 2,083 份文档 |
| 混合课程回答 | 50/50 | 归一化后答案含预期要点；一题原始字面比较因连字符判错 |
| 真实 Piazza 帖子检索 | 50/50 | 目标帖子进入前 18 条；同课程还放入 2,000 份背景文档和 63 份大纲 |
| 真实 Piazza 回答 | 50/50 | 50 题均引用目标帖子；独立模型按原始教师/助教回答核对为 50/50。原题直接使用帖子标题，因此再做改写测试 |
| Piazza 中文改写检索 | 20/20 | 用不同措辞的中文问题查询英文帖子，目标帖子进入前 18 条；只验检索，未验最终答案 |
| SyllabusQA 定位 | 50/50 | 目标课程大纲进入前 18 条；该测试已选定课程，不能代表自动课程判断 |
| SyllabusQA 首轮答案 | 30/50 | 严格对照官方简短答案；其中一些标准答案与大纲原文不一致或省略细节 |
| SyllabusQA 原文核对 | 46/50 | 收紧规则后的版本，由独立模型按整份大纲核对；仍有 4 个实质问题，包括作业分值、学术诚信规则和未明确的成绩权重 |
| SyllabusQA 页面端到端抽样 | 7/7 内容题 | 在对应课程的独立问答入口引用了正确大纲，且整份原文核对通过；另 3 题问考试日期，因历史大纲日期未摄入 PostgreSQL，系统拒绝把归档文字冒充已确认事实 |
| QASPER 候选证据 | 50/50 | 人工标记段落都出现在最多 80 个候选里 |
| QASPER 精选证据 | 48/50 | 首轮 AI 精选最多 14 段；保留前四个强检索命中后，在相同选择输出上重放为 49/50 |
| QASPER 原文核对 | 45/50 | 收紧规则后的 50 题，由独立模型按全文核对；有误读未验证结论、漏掉枚举项目或关键数值等问题 |
| QASPER 针对性修复 | 4 题单独复测通过 | 分别修复 4% RTE 数值遗漏、18 项枚举缺项、把子组件误当顶层模型；未验证偏差一题也不再把未经测试的效果当作已证实发现。未重新声称整组分数 |

人工参考答案判分和模型原文核对都不是无误的裁判；对于争议题同时保留题目、来源和两种判定，不用单一分数掩盖错误。QASPER 的“baseline”一题仍有歧义，需人工裁决。针对性修复的通过结果不能替代重新执行完整 50 题。

本任务的生产验收门槛设为：确定性事实 50/50；三个互不相同的各 50 题资料集连续达到至少 95% 的来源支持且回答正确，并抽查所有失败与冲突题；不能跨课程串证据。当前**未达到**资料准确度门槛，不能据此切换生产。真实 Piazza 50 题与混合模拟 50 题通过，但真实大纲和论文的完整回答准确度仍低于门槛；后两组主要是在已指定课程或论文范围下测得，不能推断未知课程自动路由一定准确。

这些测试检验了公开大纲、论文全文、真实 Piazza 文本，以及模拟的 Canvas、PDF 课件与邮件组合；没有检验原始 PDF 二进制提取、幻灯片视觉图表识别或真实 Canvas 导出。这个边界对学习资料中的公式和图表尤其重要。

## 可复现方式与开销

原始公开数据只缓存在被 Git 忽略的 `data/benchmark/`，不提交全文到仓库。脚本在 `scripts/benchmark-*`，其中 `benchmark-courseassist-prepare.py` 从公开 CSV 生成可读 JSON；`benchmark-kernel-truth.mjs`、`benchmark-mixed-course.mjs` 需要独立的 `KERNEL_DATABASE_URL`。SyllabusQA 和 QASPER 脚本分别先导入公开全文，再运行答案与评分。评分报告同样留在被忽略的目录。

AI 评分是辅助分析，正式上线前还需对失败题人工看原文。独立测试使用受限预算、当前应用的计费日志记账；没有修改生产模型、密钥、备份或服务。源码构建和 PostgreSQL 集成测试的结果需与资料准确度门槛分别报告。
