# 可选结构保真配置（Issue 173）

`transcribePdfVisualPages` 可显式传入 `fidelityProfile: 'structure-v1'`。仅支持指定原始页码、`imageInput: true`、`overviewImage: true`、启用既有四图模式，以及精确模型名 `gpt-5.4-mini`。未知配置或不适用组合在渲染、缓存读取和付费请求前拒绝。

该配置使用 medium 推理及既有9000输出上限。原有完整总览加四细节PNG、位置标签、顺序、图像detail和输出schema保持；每页仍一次请求。通用追加要求保留公式括号和运算符作用范围、用可见位置区分重复图标签、逐条描述实际箭头端点/方向/线型、保留空表格和可见化学键/选择标记，不推导答案、不补隐含原子。非逐字图描述必须用原件语言单列；项目符号使用可见字符。

默认配置的请求文本、low推理和缓存身份不变。新配置具有独立profile/prompt版本/effort/输出限额缓存身份，不读取或覆盖旧转写。原有不确定警告、控制字符与数学结构拒绝门保持，不清洗或自动重试错误输出。

新增一个聚焦mock场景验证新旧请求/五图/schema与缓存隔离、配置预付费拒绝和控制字符仍拒绝；不重跑旧总览检查。代码和mock通过不证明正文、公式、图或整页正确。仅拟对两张已失败页做新配置隔离诊断，仍是已曝光校准，原失败结果和历史评分保留；没有真实模型/PDF处理、部署或生产切换。
