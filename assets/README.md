`NotoSansSC-Regular.ttf` is the weight 400 static instance of
[NotoSansSC-VF.ttf](https://github.com/notofonts/noto-cjk/blob/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf),
created with fonttools `varLib.instancer`. It is embedded in sketchbook PDFs so
Chinese text renders without requiring fonts on the reader's device. The font
is licensed under the SIL Open Font License in `OFL.txt`.
